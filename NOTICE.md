# Project lineage and attribution

KhinsiderDownloader is a desktop application for searching
[downloads.khinsider.com](https://downloads.khinsider.com/) and downloading
albums in bulk.

## Original project

The original KhinsiderDownloader was created by **Weespin** and is available at
<https://github.com/weespin/KhinsiderDownloader>.

    Original work Copyright (C) 2025 Weespin

## This repository

This repository is a GitHub fork of the original project, maintained
independently by **Octavio Silva (FrankenSama)** with its own changes, release
schedule and support. It is **not** the official KhinsiderDownloader build, and
issues with this version should be reported to this repository rather than to
the original author.

    Modifications Copyright (C) 2026 FrankenSama

Contributors to both the original project and this fork are listed in
[CONTRIBUTORS.xml](CONTRIBUTORS.xml).
